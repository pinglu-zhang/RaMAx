# RaMAx 1.1.0

RaMAx 1.1.0 releases the committed `dev` implementation for multi-genome
alignment and MAF, HAL, PAF and GFA output on Linux x86-64.

## Changes

- Native HAL export through the bundled HAL library, without a Cactus append
  executable. Leaf contig names and softmask are preserved.
- Shared, bounded MAF/HAL export preparation and earlier release of graph
  storage when remaining outputs no longer require it.
- Explicit first-round reference selection and a least-fragmented nonempty
  fallback when all genomes exceed the automatic reference sequence limit.
- Recovery of non-overlapping PAF fragments during graph-safe normalization.
- Versioned Conda and Docker Hub distributions with source checks,
  four-format integration checks and fresh-install validation.

Experimental `dev-pan` changes, including automatic execution modes, round
budgets and collinear final refinement, are not part of this release.
The public CLI and restart schema follow the committed `dev` implementation.

## Install

```bash
conda install -c malab -c conda-forge -c bioconda ramax=1.1.0
ramax --version
```

```bash
docker pull pingluzhang/ramax:1.1.0
docker run --rm pingluzhang/ramax:1.1.0 --version
```

Both distributions include the configured Mash, wfmash, Samtools/HTSlib and
minipoa runtime dependencies. The release targets Conda `linux-64` and Docker
`linux/amd64`; no standalone binary bundle is provided.

## Source and artifact identity

The annotated `v1.1.0` tag identifies the validated master release commit.
The attached Conda package, `SHA256SUMS` and `BUILD_INFO.json` record the package
checksum, source commit and Docker digest. The `1.2` and `latest` Docker aliases
are advanced after validation of the versioned public installations.

Installed-product checks validate packaging and the small integration fixture;
they do not replace dataset-specific alignment-quality or performance benchmarks.
