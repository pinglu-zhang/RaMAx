# RaMAx 1.1.1

- Balance first-round wfmash chunks within the thread and genome-pair limits.
- Use the legacy glibc fast spawn path for external tools and preserve process
  groups for cancellation. Install a small helper to enter minipoa's scratch
  directory on builds without the native spawn chdir action.
- Prefer tmpfs before ordinary files when memfd is unavailable. Allow a
  job-private local scratch directory through `RAMAX_MINIPOA_TMPDIR`.
- Forward the build sysroot and compiler flags to sonLib and HAL. Require
  actual glibc 2.17 runtime acceptance for the Conda build, including MAF,
  HAL, PAF and GFA export and content checks.

```bash
conda install -c malab -c conda-forge -c bioconda ramax=1.1.1
docker pull pingluzhang/ramax:1.1.1
docker run --rm pingluzhang/ramax:1.1.1 --version
```

The release assets record the source commit, Conda SHA-256 and Docker digest.
